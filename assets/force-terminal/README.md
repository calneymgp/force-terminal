# Force Terminal — proposta de símbolo

Rascunho original de um monograma **F** com barras de terminais diagonais e um chevron de prompt. A silhueta simples busca continuar legível em 16, 24 e 32 px.

- `force-symbol.svg`: símbolo transparente e monocromático, herdando a cor por `currentColor`.
- `force-app-icon.svg`: composição quadrada com cantos arredondados para avaliar como ícone do aplicativo.
- `force-logo-preview.png`: prévia renderizada do ícone do aplicativo.
- Paleta de referência: navy `#111827` e mint `#64E3AF`.

Este material é uma proposta para revisão. Ainda não representa uma marca aprovada nem foi aplicado ao aplicativo.
