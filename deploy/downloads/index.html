Baixar instalador para Mac · 201 MB

Depois do download, abra o arquivo DMG e arraste o Force Terminal para a pasta Aplicativos. Por ser uma versão de teste, o macOS pode pedir autorização na primeira abertura.

Para iniciar agentes, o Claude Code deve estar instalado no Mac. Execução de agentes por SSH e Codex ainda não está disponível. Esta versão de teste é para a rede Tailscale e não inclui atualizações automáticas.
